# Ciel · BOZUU’s little journey

Браузерная игра для изучения французских слов через поиск английских переводов. Опоссум BOZUU несёт звёздочку к маяку: каждая пройденная тема зажигает один из 50 огоньков.

## Запуск

```sh
python3 -m http.server 5173 --bind 127.0.0.1
```

Откройте http://localhost:5173. Также можно выполнить `npm start`. Установка зависимостей для игры не нужна. При обновлении уже открытой версии используйте Ctrl+Shift+R.

## Что реализовано

- 50 тем, 530 французско-английских пар, отдельная SVG-иллюстрация для каждой темы.
- Крупные карточки и пагинация без внутренней прокрутки: 8 карточек на компьютере, 4 на телефоне, 2 на низком мобильном экране. Нажатие сразу запускает раунд.
- 10 успешных совпадений за раунд. Минимум две полноценные пары на поле; максимум пять на компьютере и три на телефоне. В конце может вернуться знакомая пара для повторения, чтобы единственная оставшаяся пара не подсказывала ответ.
- Три округлые формы и три размера шариков, плавное движение и появление волнами. Существующие шарики сохраняют свои места.
- Произношение из 530 готовых локальных MP3. Голос fr-FR-DeniseNeural, скорость -10%, генерация через edge-tts. Браузерный синтез используется лишь как резерв при ошибке загрузки файла.
- Звуки выбора, ошибки, совпадения и завершения. Три тихих варианта POP: вероятность 25% на волну, пауза между такими волнами минимум 15 секунд.
- При совпадении: увеличение шариков, световая линия, крупные кольца и частицы. BOZUU появляется на переднем плане только при каждом пятом поводе для поздравления; счётчик сохраняется между раундами. Новый персонаж крупнее, в кепке и кедах, с подмигиванием и победным жестом.
- Постоянный прогресс маршрута, лучшая серия и предпочтение сложных слов в следующих раундах. Повтор темы не увеличивает число пройденных остановок.
- Русский и английский интерфейс с сохранением выбора. Языки учебных пар всегда French → English.
- Небо по локальному времени устройства: рассвет 05–08, день 08–18, закат 18–21, ночь 21–05. Плавные переходы, ночные звёзды, редкий декоративный дождик; геолокация и реальная погода не используются.
- Мышь, сенсорное управление, Tab и Enter/Space. Отключение звука и движения, поддержка prefers-reduced-motion. Декоративные эффекты не перехватывают нажатия.

Прогресс хранится только в браузере под ключом `ciel-v1`; между устройствами не синхронизируется. Шрифты загружаются из Google Fonts с системным запасным шрифтом. Иллюстрации и аудио находятся в проекте.

## Проверка

```sh
node game.test.js
```

Тестируются словарь, 50 тем, 530 пар, уникальные иллюстрации, выбор раунда, проверка совпадений, приоритет ошибок и границы времени суток.

Проверено автоматизацией Chromium: прохождение раунда, изменение языка, сохранение маршрута, эффекты, ограничение звуков POP, галерея, мобильные размеры и загрузка MP3. Все аудиофайлы дополнительно проверены декодированием через FFmpeg. Это техническая проверка, а не экспертная вычитка произношения.

## Файлы

- `app.js`: игра, прогресс, аудио и интерфейс.
- `game.js`, `themes.js`: игровая логика и словарь.
- `i18n.js`: русский и английский интерфейс.
- `theme-art.js`, `bozuu.svg`, `cloud.svg`: оригинальные векторные иллюстрации.
- `sky.js`: локальное время и декоративная погода.
- `style.css`, `flight.css`, `delights.css`, `journey.css`: оформление и анимации.
- `audio/`: готовая озвучка.

Статический сайт: сервер приложений, регистрация и API-ключи не требуются. Следующие возможные этапы: PWA, проверка словаря носителем языка и синхронизация прогресса.
